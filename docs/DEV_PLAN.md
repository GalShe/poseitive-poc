# תוכנית פיתוח: מ-POC ל-M2 (17.3.27)

כל משימה: ענף או commit משלה, בדיקות עוברות, ומה שנבנה עובד מקצה לקצה לפני שעוברים לבאה.
הסדר בנוי כך שבכל שלב יש מערכת שעובדת, גם אם חלקית.

## שלב 0: תשתית (שבוע 1)
- [ ] **מבנה monorepo**: `packages/core` (הליבה מ-`web/js/core` + `exercises.js`, ב-TypeScript), `apps/patient` (אפליקציית המטופל), `apps/therapist` (ממשק המטפל), `apps/api` (NestJS). npm workspaces.
  - קבלה: הבדיקות הקיימות עוברות על `packages/core`; ה-POC הנוכחי ממשיך לעבוד.
- [ ] **Docker Compose** ל-PostgreSQL בפיתוח, ו-CI שמריץ את כל הבדיקות בכל push.

## שלב 1: שרת, משתמשים והרשאות (שבועות 2–3)
- [ ] NestJS + Prisma/TypeORM מעל הסכמה מ-`db/schema_postgres.sql`.
- [ ] הרשמה (מייל, סיסמה, שם), סיסמאות ב-hash, סטטוס PENDING, התחברות עם JWT.
- [ ] תפקידים ו-Guards: מנהל / מטפל / מטופל. **Row-Level Security ב-PostgreSQL**: מטפל רואה רק את המטופלים שלו.
  - קבלה: בדיקות שמוודאות שמטפל א' לא יכול לקרוא נתונים של מטופל של מטפל ב', ושמנהל לא רואה נתוני אימון.
- [ ] ממשק מנהל: אישור משתמשים, קישור מטופל למטפל.

## שלב 2: מטפל: תרגילים וייחוס (שבועות 4–6)
- [ ] ספריית תרגילים (3 התרגילים של הפיזיותרפיסט) והקצאה למטופל: סטים, חזרות, תדירות.
- [ ] **הקלטת ייחוס במפגש**: המטפל מצלם 3+ חזרות של המטופל; נשמרים רצפי מדדים (לא וידאו).
- [ ] **ייחוס סטטיסטי**: לכל מפרק, ממוצע ± סטייה על זמן מנורמל ("מסדרון"); ספים אישיים נגזרים ממנו.
  - קבלה: על סרטוני ה-POC (`ref_*`, `lean_*`) ההתרעות לא גרועות ממה שה-POC השיג (90% זיהוי, 0% שווא).

## שלב 3: מטופל: אימון (שבועות 7–9)
- [ ] מסכי בית / היום שלי / התרגילים שלי (עברית RTL, אנגלית אופציונלית).
- [ ] אימון מול מצלמה עם המנוע, משוב קולי, ספירת חזרות; עיבוד ב-15–20 FPS.
- [ ] **בדיקת מיקום לפני אימון** (זווית, מרחק, כל המפרקים נראים).
- [ ] **שאלת כאב (VAS)** בסוף אימון; ‏≥7 → המלצה לעצור + התרעה למטפל. כפתור עצירה.
- [ ] שמירה מקומית (IndexedDB) וסנכרון.

## שלב 4: מעקב (שבועות 10–11)

- [ ] מטופל: גרפי התקדמות, רצף ימים.

## שלב 5: הצ'אט להגדרת תרגילים (שבועות 12–14)

  - קבלה: על התיאורים המילוליים של הפיזיותרפיסט (3 תרגילים) ההגדרה המופקת מזהה את הטעויות שהדגים.
