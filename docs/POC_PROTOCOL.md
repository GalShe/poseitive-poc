# פרוטוקול הבדיקות של ה-POC

זמן כולל: בערך שעה וחצי. צריך שני אנשים: אחד מתאמן ואחד מצלם.

## ציוד
- טלפון לצילום, וחצובה או משהו יציב להניח עליו את הטלפון (ערימת ספרים מספיקה).
- כיסא רגיל בלי גלגלים.
- **מומלץ:** אפליקציית גוניומטר בטלפון השני, או גוניומטר אמיתי.
- בגדים צמודים בצבע שונה מהקיר שמאחור (המלצה ממאמר [4] בסקר הספרות).

## הכנה: מדידת זווית הברך על הכיסא (פעם אחת)
1. יושבים על הכיסא, כפות הרגליים על הרצפה, השוקיים כמעט אנכיות.
2. מודדים את זווית הברך בגוניומטר: ציר הגוניומטר על הברך, זרוע אחת לאורך הירך (לכיוון הירך הגדולה), השנייה לאורך השוק (לכיוון הקרסול).
3. רושמים את המספר. אם אין גוניומטר, מניחים 90°.

בסקווט "לכיסא" יורדים עד שהישבן **רק נוגע** בכיסא ומחזיקים 3 שניות בלי לשבת. בתנוחה הזאת הזווית שווה למה שמדדתם.

## חלק א: בדיקת ביצועים בטלפון (10 דקות)
לכל טלפון: האייפון, האנדרואיד של החבר, וכל טלפון נוסף שיש.

1. פותחים את האתר: `https://galshe.github.io/poseitive-poc/`
2. ממלאים **דגם המכשיר** (למשל `iPhone 13`).
3. בוחרים מצלמה **אחורית** ולוחצים **הפעל מצלמה**. מאשרים גישה למצלמה.
4. מניחים את הטלפון יציב, המתאמן עומד **מהצד** במרחק של 2.5 מטר בערך ונראה מכף רגל ועד ראש.
5. לוחצים **התחל בדיקת ביצועים** ועושים סקווטים לאורך 30 שניות.
6. לוחצים **שתף תוצאה** ושולחים את הקובץ (וואטסאפ או מייל לעצמכם).
7. **אם יש זמן:** חוזרים על הבדיקה עם מודל **Full**, ועם מעבד **CPU**.

קבצים שמתקבלים: `live_<מכשיר>_<תאריך>.json` נכנסים ל-`results/live/`.

## חלק ב: צילום הסרטונים (בערך שעה)
**הגדרות צילום לכל הסרטונים:**
- הטלפון יציב, בגובה המותן, **מהצד** (המתאמן בפרופיל למצלמה).
- הטלפון **לאורך** (portrait), 30 פריימים לשנייה. ההגדרה הרגילה של המצלמה מתאימה.
- כל הגוף בפריים כל הזמן, כולל כפות הרגליים.
- בתחילת כל סרטון עומדים 2 שניות בלי לזוז.

| שם הקובץ | מה עושים | כמה חזרות |
|---|---|---|
| `cond_strong_2m.mp4` | אור חזק (תאורה מלאה בחדר + אור יום), מרחק 2 מטר | 5 סקווטים לכיסא, החזקה 3 שנ׳ |
| `cond_strong_3.5m.mp4` | אור חזק, מרחק 3.5 מטר | 5, החזקה 3 שנ׳ |
| `cond_weak_2m.mp4` | אור חלש (מנורה אחת, וילון סגור) | 5, החזקה 3 שנ׳ |
| `cond_weak_3.5m.mp4` | אור חלש, 3.5 מטר | 5, החזקה 3 שנ׳ |
| `cond_back_2m.mp4` | **חלון מאחורי המתאמן** (תאורה אחורית) | 5, החזקה 3 שנ׳ |
| `cond_back_3.5m.mp4` | תאורה אחורית, 3.5 מטר | 5, החזקה 3 שנ׳ |
| `ref_1.mp4`, `ref_2.mp4`, `ref_3.mp4` | **סקווט תקין** באור רגיל, 2.5 מטר, בקצב רגיל, **בלי** החזקה | 5 בכל סרטון |
| `lean_1.mp4`, `lean_2.mp4` | סקווט עם **הישענות יתר של הגב קדימה** (בכוונה): החזה יורד לכיוון הברכיים | 5 בכל סרטון |
| `shallow_1.mp4` (לא חובה) | סקווט **רדוד**: יורדים רק חצי מהדרך | 5 |

**אם מדדתם זווית בגוניומטר** שהיא לא 90°, יוצרים קובץ `data/groundtruth.csv`:
```
video,angle
cond_strong_2m,94
cond_strong_3.5m,94
```

## חלק ג: לשלוח
- את הסרטונים: בצ'אט עם Claude, או להעלות ל-`data/videos/` (התיקייה לא נשמרת ב-GitHub, הסרטונים נשארים אצלכם).
- את קובצי ה-JSON מהטלפונים.

## מה קורה עם הנתונים
`python analysis/run_poc.py` מחלץ את השלד מכל סרטון, מריץ את הטסטים ומעדכן את לשונית **תוצאות POC** באתר.
נשמרות רק נקודות השלד (`data/extracted/*.csv`). **הווידאו עצמו לא נשמר בריפו.**
