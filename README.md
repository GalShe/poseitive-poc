# Poseitive POC

הוכחת היתכנות לפרויקט **Poseitive**: מערכת מבוססת ראייה ממוחשבת לניטור ושיקום פיזיותרפי ביתי.
אור שמש וגל שמש · מנחה: ד״ר זיו יקותיאלי

**האפליקציה החיה:** https://galshe.github.io/poseitive-poc/

ה-POC סוגר את אי־הוודאויות מטבלה 4.2 במסמך הייזום שחוסמות את תכנון הארכיטקטורה (M1).
התרגיל שנבחר לבדיקה הוא **סקווט בצילום מהצד**: זווית הברך קלה לאימות מול 90°, ותנועת הפיצוי **הישענות יתר של הגב קדימה** מוגדרת במבחן ה-Overhead Squat Assessment של NASM (הגו צריך להישאר מקביל לשוק).

## תרגילים (מאז 28.10.26)

שלושה תרגילים לפי הדגמה ותיאור של הפיזיותרפיסט המלווה. כל תרגיל מוגדר **כנתונים** ב־[`web/js/exercises.js`](web/js/exercises.js), ומנוע אחד ([`exercise-engine.js`](web/js/core/exercise-engine.js)) מריץ את כולם. המדדים עצמם נמצאים בספרייה אחת ([`metrics.js`](web/js/core/metrics.js)).

| תרגיל | מטופל | צילום | מדד עיקרי | טעות שמזוהה | מודלים |
|---|---|---|---|---|---|
| סקווט עם תמיכה | אחרי החלפת ברך | מהצד | כפיפת ברך | בריחה אחורה עם הישבן (נטיית גו) | שלד |
| הרמת זרוע עם מקל | אחרי שבר בכתף | מקדימה | הרמת זרוע | נטיית הגוף הצידה (הטיית קו הכתפיים) | שלד |
| כפות צמודות והורדה | אחרי שבר בשורש כף היד | מקדימה | כפיפת שורש כף היד (הערכה מזווית האמה) | פתיחת הכפות; אצבעות לא כלפי מעלה | שלד + כפות ידיים |

- **משוב בשתי שכבות:** התרעה כתובה וקולית בזמן התנועה (טעות שנמשכת 300ms לפחות), וסיכום בסוף כל חזרה. ספירת החזרות נאמרת בקול.
- **משוב קולי בעברית** דרך מנוע הדיבור של המכשיר ([`voice.js`](web/js/voice.js)). אם אין קול עברי במכשיר, יושמעו צפצופים.
- **מודל כפות הידיים** ([MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker)) נטען רק לתרגיל שמצהיר עליו. כשהכפות צמודות הוא לא מפריד בין שתי הידיים, אבל כיוון היד שהוא מחזיר נכון, ולכן משמש רק לכיוון האצבעות.
- **הספים ראשוניים:** נקבעו מסרטון ההדגמה של הפיזיותרפיסט (כל טעות הודגמה פעם אחת). המנוע הורץ על הסרטון והחזרות שסומנו תואמות להדגמה. בדיקה: `node web/tests/replay.mjs <frames.json> <exercise> <from> <to>` (סרטון ההדגמה עצמו לא נשמר בריפו).

## איך זה עובד

### 1. זיהוי שלד
[MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) מחזיר בכל פריים 33 נקודות ציון (x, y מנורמלים 0..1, ו-visibility).
המנוע עטוף בממשק אחד ([`web/js/engine.js`](web/js/engine.js)), כך שאפשר להחליף אותו בלי לגעת בשאר הקוד. זו פעולת המנע לסיכון "הפסקת תמיכה במנוע הזיהוי" (טבלה 4.3).

### 2. חישוב זוויות ([`geometry.js`](web/js/core/geometry.js) / [`geometry.py`](analysis/poseitive/geometry.py))
- הנקודות מומרות **לפיקסלים** לפני החישוב, אחרת בווידאו 16:9 הזוויות יוצאות מעוותות.
- **זווית ברך** = הזווית בנקודת הברך בין הקטע ברך→ירך לקטע ברך→קרסול: ‎`acos( (v1·v2) / (|v1||v2|) )`‎. ‏180° = רגל ישרה.
- **נטיית הגו** = זווית הקטע ירך→כתף מול האנך. **נטיית השוק** = זווית הקטע קרסול→ברך מול האנך.
- **הישענות יתר** = נטיית הגו פחות נטיית השוק. בסקווט תקין שתיהן דומות. אם ההפרש גדול מהסף (ברירת מחדל 38°, כויל בבדיקה הראשונה; ניתן לשינוי בסליידר), מוצגת התרעה.
- נבחר הצד של הגוף שקרוב למצלמה, לפי ערכי ה-visibility.
- החלקה (EMA, α=0.5) מצמצמת רעש בין פריימים.

### 3. ספירת חזרות ([`reps.js`](web/js/core/reps.js))
מכונת מצבים עם שני ספים (היסטרזיס): ירידה מתחת ל-120° = "בתוך סקווט", עלייה מעל 160° = חזרה הושלמה. שני ספים שונים מונעים ספירה כפולה כשהזווית רועדת.
לכל חזרה נשמרים העומק המרבי, ההישענות המרבית ורצף הזוויות.

### 4. משוב בשתי שכבות (כמו שתוכנן בסקר הספרות, בעקבות מאמר [2])
- **במהלך התנועה:** בדיקה מיידית של הישענות מול הסף. התרעה אדומה על המסך וצפצוף.
- **בסוף כל חזרה:** סיכום החזרה (עומק, הישענות) והשוואה לביצוע הייחוס ב-**DTW** ([`dtw.js`](web/js/core/dtw.js)), שמיישר רצפים בקצבים שונים.

### 5. מדידת ביצועים ([`perf.js`](web/js/core/perf.js))
- **זמן עיבוד:** כמה זמן לוקח למודל לעבד פריים אחד.
- **FPS:** כמה פריימים עובדו בשנייה.
- **השהיה:** מרגע צילום הפריים (`captureTime` של `requestVideoFrameCallback`, כשהדפדפן מספק אותו) ועד שהמשוב צויר. כשהדפדפן לא מספק את רגע הצילום, המדידה מתחילה מהרגע שהפריים הגיע לדפדפן, וזה מסומן בתוצאה.

## הרצה

```bash
pip install -r requirements.txt

# בדיקות יחידה
python -m pytest analysis/tests -q
node web/tests/core.test.mjs

# טסטי ה-POC (אחרי שהסרטונים ב-data/videos)
python analysis/run_poc.py

# השוואת מסדי נתונים (רץ גם אוטומטית ב-GitHub Actions)
python db/benchmark.py --pg postgresql://... --mongo mongodb://...

# האפליקציה מקומית
cd web && python -m http.server 8000   # http://localhost:8000
```
